# Asset Checklist — Whimsical Moss

## Brand assets
- [ ] Confirmed brand spelling and capitalisation
- [ ] Logo/wordmark, if one exists
- [ ] Optional real handwritten signature or hand-lettered brand name
- [ ] Official Instagram profile URL
- [ ] WhatsApp number in international format
- [ ] Domain name, if purchased
- [ ] Preferred email/contact details, if any

## Photography
- [ ] Hero image of a standout creation
- [ ] 3–6 images of pipe-cleaner crafts
- [ ] 2–4 calligraphy examples
- [ ] 2–4 painting examples
- [ ] 2–4 custom or unusual creations
- [ ] 3–6 process photos showing hands/materials
- [ ] Maker portrait or working portrait, with permission
- [ ] Close-up texture/detail images
- [ ] Lifestyle or gifting photos, if available

## For each image
- [ ] Confirm owner has permission to publish it
- [ ] Identify what the item is
- [ ] Provide a short title or description
- [ ] Provide accurate alt text or approve a draft
- [ ] Confirm whether the item is an example, available item, or past commission
- [ ] Optimise image dimensions and file size
- [ ] Keep the original master file separately

## Copy and policies
- [ ] Approved maker introduction
- [ ] Confirmed description of each craft category
- [ ] How custom enquiries work
- [ ] Whether pricing or starting prices should be displayed
- [ ] Typical creation time, only if owner is comfortable making a qualified claim
- [ ] Delivery/pickup coverage, if relevant and confirmed
- [ ] Payment/deposit process, if relevant and confirmed
- [ ] Any return/cancellation policy, if relevant and confirmed
- [ ] Permission for any testimonials or customer photos

## Visual motifs
- [ ] One original flower/leaf doodle
- [ ] A few original stars/arrows/annotation marks
- [ ] Optional hand-lettered phrase
- [ ] Optional subtle local motif tied to the artist's real story

## Minimum viable launch set
At minimum, try to collect:
- 1 strong hero image
- 6–10 real work images across the actual categories
- 2–4 process photos
- 1 approved maker introduction
- verified WhatsApp and Instagram links
