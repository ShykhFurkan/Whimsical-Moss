# QA Checklist — Whimsical Moss Stage 1

## Content and trust
- [ ] Brand name and logo are correct.
- [ ] All factual claims are owner-approved.
- [ ] No fake testimonials, ratings, numbers, or awards.
- [ ] All production gallery images are real, approved brand work.
- [ ] No development placeholders remain.
- [ ] Custom-order wording does not imply an order is confirmed automatically.
- [ ] Any pricing, delivery, timing, and payment statements are confirmed.

## Layout
- [ ] Test 360px and 390px mobile widths.
- [ ] Test tablet portrait and landscape.
- [ ] Test laptop and wide desktop.
- [ ] No unintended horizontal scroll.
- [ ] Images maintain intended aspect ratios.
- [ ] Text does not overlap decorations.
- [ ] Header/navigation works on mobile.
- [ ] Tap targets are comfortable.

## Links and functionality
- [ ] Logo/home link works.
- [ ] Section navigation links work.
- [ ] WhatsApp opens the correct number.
- [ ] WhatsApp prefilled message is readable and encoded correctly.
- [ ] Instagram opens the correct official profile.
- [ ] External links behave as intended.
- [ ] No empty buttons or decorative controls pretending to be interactive.

## Accessibility
- [ ] Logical heading hierarchy.
- [ ] Keyboard can reach and activate all links and controls.
- [ ] Focus indicator is visible.
- [ ] Text contrast is adequate.
- [ ] Meaningful images have descriptive alt text.
- [ ] Decorative images are hidden from assistive technology where appropriate.
- [ ] Reduced-motion setting disables/simplifies nonessential movement.
- [ ] Page remains usable without hover.

## Performance
- [ ] Hero image is appropriately sized and prioritised.
- [ ] Below-the-fold images are lazy-loaded.
- [ ] Image dimensions/aspect ratios prevent layout shift.
- [ ] Fonts are limited to necessary families/weights.
- [ ] No unnecessary animation library or third-party script.
- [ ] Video is compressed and not blocking the initial viewport.
- [ ] No major console errors.
- [ ] Production build passes.

## SEO and sharing
- [ ] Page title and meta description are present.
- [ ] Canonical URL is correct once the domain is known.
- [ ] Open Graph image/title/description are configured.
- [ ] Favicon is set.
- [ ] Links have meaningful text.
- [ ] No accidental `noindex` directive on production.

## Final approval
- [ ] Owner approves visual design.
- [ ] Owner approves all copy.
- [ ] Owner approves real imagery.
- [ ] Owner tests WhatsApp and Instagram links.
- [ ] Production deployment is checked on a real phone.
